# Legal Metrology Compliance System

A cross-platform mobile and web application built using **React Native (Expo)** and **FastAPI** to verify Legal Metrology (Packaged Commodities) Rules, 2011 compliance automatically via OCR and AI inspection tools.

---

## 🚀 Features

* **Role-Based Access Control**: Separate interfaces for Field Inspection Officers and Supervisory Officers.
* **Commodity Scanner**: Automated compliance checking using EasyOCR / Python backend processing.
* **Web & Mobile Support**: Built with React Native & Expo for deployment across Web, Android, and iOS.
* **GitHub Pages Ready**: Fully configured automated web build and deployment pipeline.

---

## 🛠️ Tech Stack

* **Frontend**: React Native, Expo, React Native Web, NativeWind (Tailwind CSS)
* **Backend**: Python, FastAPI, EasyOCR, SQLite
* **Deployment**: GitHub Pages (`gh-pages`), ngrok (Local Development Tunneling)
